# Project Statement

## Problem Statement
Campus resources are often shared by multiple students and faculty members. Without a centralized system, resource availability, booking conflicts, and utilization can be difficult to track.

## Scope
This project provides a terminal-based system to manage campus resources and their bookings. It supports resource CRUD operations, booking creation/cancellation, conflict detection, persistence, and utilization reporting.

## Target Users
- Students
- Faculty members
- Laboratory/resource coordinators

## High-Level Features
- Add, update, remove, and list resources
- Search resources by name/type/status
- Create and cancel bookings
- Detect overlapping bookings
- Persist data using CSV files
- Generate utilization reports
- Validate user input and handle errors
